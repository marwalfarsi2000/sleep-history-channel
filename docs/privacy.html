Privacy Policy

Sleep History Automation is a private tool used only by its owner to upload approved videos to the owner's own YouTube channel.

Data accessed

With the owner's consent, the app uses Google OAuth to access the YouTube Data API: uploading videos and reading the owner's own channel and video list to avoid duplicate uploads.

Use and storage

OAuth tokens are stored only as encrypted secrets in the owner's GitHub Actions environment. No Google user data is sold, shared with third parties, or used for advertising. No data from any other user is collected.

Revoking access

Access can be revoked at any time from Google Account permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
